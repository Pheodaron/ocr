Document OCR API

Открыть клиент

Асинхронное распознавание PDF. Автоматическая схема OpenAPI JSON.

МетодПутьРезультат
POST/api/documentsmultipart/form-data: file, backend (по умолчанию paddle). Ответ 202: ID и начальный статус.
POST/api/runsJSON: backend, filenames (1–1000 имён). Создать запуск перед загрузкой файлов; ответ 201 с ID и составом.
GET/api/runs?limit=20&offset=0Список запусков со статусами и признаком has_more. limit: 1–100.
GET/api/runs/{id}Документы запуска: принятые задания, ошибки, ещё не загруженные и удалённые файлы.
POST/api/runs/{id}/finish-uploadJSON: failures [{position,error}]. Сохранить ошибки и завершить загрузку запуска.
GET/api/runs/{id}/report?format=html|jsonСкачать отчёт только этого запуска, включая ошибки загрузки и удалённые документы.
POST/api/comparisonsfile и повторяемое поле backends. Ответ 202: ID сравнения и задания всех конфигураций.
GET/api/comparisons/{id}Статусы и время прогонов одного PDF.
GET/api/configДоступные движки, квантизации и лимиты.
GET/api/documentsПоследние 30 заданий.
POST/api/documents/statusJSON: document_ids (1–1000 ID). Статусы выбранных документов и список missing для удалённых.
POST/api/reports?format=html|jsonJSON: document_ids (до 1000 ID), необязательные upload_errors. Отчёт: страницы, время, модель, CPU/RAM и пайплайн. Поддерживает промежуточный снимок активных заданий.
GET/api/documents/{id}Статус и количество обработанных, успешных, ошибочных страниц.
POST/api/documents/{id}/cancelОстановить задание, включая текущую страницу. Ответ 202: cancelling или cancelled; завершённые задания сохраняют свой статус.
DELETE/api/documents/{id}Удалить PDF и результаты при любом статусе. Работающий процесс сначала останавливается. Ответ 200: deleted или 202: deleting. Задание сразу исчезает из списков.
GET/api/documents/{id}/resultJSON результата. Ответ 409, пока обработка не завершена.
GET/api/documents/{id}/download?format=json|markdown|htmlСкачать результат файлом.
GET/api/documents/{id}/pages/{number}/imagePNG страницы с исправленной ориентацией. Нумерация с 1.
GET/api/documents/{id}/pages/{number}/previewОчищенный HTML-предпросмотр Markdown/HTML результата страницы.
GET/healthРаботоспособность API и сведения о worker.
GET/ready200, если координатор очереди отвечает; иначе 503. Веса загружаются при выполнении задания.

Загрузка:

curl -F 'file=@document.pdf' http://localhost:8000/api/documents

Получение результата:

curl http://localhost:8000/api/documents/ID/result

Отчёт обработки нескольких документов:

curl -X POST -H 'Content-Type: application/json' \
  -d '{"document_ids":["ID_ПЕРВОГО","ID_ВТОРОГО"]}' \
  'http://localhost:8000/api/reports?format=html' -o report.html

Клиент создаёт запуск и загружает каждый PDF отдельным запросом POST /api/documents с backend, run_id и file_index (индекс от 0). Ошибка одного файла не отменяет остальные задания. Повторная загрузка той же позиции возвращает уже созданное задание. Запуски, состав файлов, ошибки и результаты хранятся на сервере; документ открывается из запуска в модальном окне.

Новые результаты содержат pages[].passes[].stages (рендер PDF, DPI и размеры, сохранение PNG, предобработка/инференс, запись raw JSON и разбор), pages[].metrics.resources (CPU seconds и пик суммы RSS по замерам через 100 мс) и engine.cpu_policy (потоки, affinity, nice, квота). Время страницы исключает очередь и загрузку модели. Неизмеренные данные старых результатов не восстанавливаются задним числом.

Статусы: queued → processing → completed / partial / failed. Остановка: cancelling → cancelled. Готовые страницы остановленного задания доступны в результате и выгрузках; необработанные имеют статус cancelled. partial означает, что часть страниц не обработана. needs_review — независимый признак необходимости проверки распознавания.

Координаты: [x_min, y_min, x_max, y_max], в пикселях изображения страницы после исправления ориентации. OCR score не является вероятностью достоверности значения.

Для генеративного OCR confidence = null и needs_review = true. Координаты могут быть null; исходный layout dots остаётся в raw-ответе на сервере. Статистика generation находится в pages[].metrics, исходные ответы — page-N-DPI.raw.json в каталоге задания.
