Document OCR API

Открыть клиент

Асинхронное распознавание PDF. Автоматическая схема OpenAPI JSON.

МетодПутьРезультат
POST/api/documentsmultipart/form-data, поле file. Ответ 202: ID и начальный статус.
GET/api/documentsПоследние 30 заданий.
GET/api/documents/{id}Статус и количество обработанных, успешных, ошибочных страниц.
GET/api/documents/{id}/resultJSON результата. Ответ 409, пока обработка не завершена.
GET/api/documents/{id}/download?format=json|markdown|htmlСкачать результат файлом.
GET/api/documents/{id}/pages/{number}/imagePNG страницы с исправленной ориентацией. Нумерация с 1.
GET/healthРаботоспособность API и сведения о worker.
GET/ready200, если модели загружены и worker отвечает; иначе 503.

Загрузка:

curl -F 'file=@document.pdf' http://localhost:8000/api/documents

Получение результата:

curl http://localhost:8000/api/documents/ID/result

Статусы: queued → processing → completed / partial / failed. partial означает, что часть страниц не обработана. needs_review — независимый признак необходимости проверки распознавания.

Координаты: [x_min, y_min, x_max, y_max], в пикселях изображения страницы после исправления ориентации. OCR score не является вероятностью достоверности значения.
